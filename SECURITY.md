# Security Policy

## Supported versions

Only the latest version on the `main` branch is currently supported.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability. Use GitHub Security Advisories or contact the repository maintainer privately with a clear description, reproduction steps, affected configuration, and impact assessment.

We will investigate privately and coordinate disclosure after a fix is available.

Never send real credentials, private keys, refresh tokens, or personal data in a report.
